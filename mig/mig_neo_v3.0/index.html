    NEO v2.3 → v3.0 への移行¶

    ゆかコネNEO v3.0 は、ソフトの土台（.NET）を作り直した大きな更新です。 設定は「自動で入るもの」と「自分で 1 回だけ操作が要るもの」に分かれます。 このページは、上げる前に知っておくことと、上げたあとにやることをまとめたものです。

    配信の直前に上げないでください

    v3.0 はまだ先行開発版（ベータ）です。上げたあとに設定の取り込みと確認が必要になるので、 時間に余裕があるときに作業してください。v2.3 はそのまま残しておけます（別フォルダに入れてください）。

    1. かんたん版：これだけやれば動きます¶

    ステップ 1. 別のフォルダに入れる¶

    v3.0 は v2.3 と同じフォルダに上書きしないでください。中身の構成が変わっています。

    1. ダウンロードページから v3.0 の ZIP を落とします
    2. v2.3 とは別の新しいフォルダに展開します（例：C:\YNC_Neo_v30）
    3. その中の YNC_Neo.exe を起動します

    容量は v2.3 より小さくなりました

    v3.0 は動かすのに必要な部品（.NET 10 ランタイム）を全部持っています。 そのぶんは増えていますが、内蔵ブラウザを使う 4 つのプラグインが Chromium の同梱をやめて WebView2 に変わったため、差し引きで小さくなりました。

    v2.3 v3.0
    内蔵ブラウザ 約 354MB 約 1.7MB
    コメントスクリーン連携 約 354MB 約 1.7MB
    ニコニコ生放送連携 約 365MB 約 11.9MB
    clusterウェブトリガ 約 354MB 約 1.7MB

    展開後はおよそ 1GB です。「.NET をインストールしてください」と言われることはありません。

    ステップ 2. 設定を取り込む¶

    初回起動のとき、v2.3 の設定を自動で探して読み込みます。 ただし、v2.3 と v3.0 で意味が変わってしまった項目がいくつかあるので、 1 回だけ手動の取り込みをしてください。

    1. 左メニューの 「設定の保存・復元」 を開きます
    2. 「v2.3設定を移行」 ボタンを押します
    3. 見つかった設定ファイルの場所と日付が出るので、確認して はい
    4. 取り込んだあとに出るお知らせの文章は必ず読んでください（下の「お知らせに出るもの」参照）
    5. ゆかコネNEO を再起動します

    元に戻せます

    取り込みの前に、自動で復元ポイント（設定フォルダのコピー）が作られます。 うまくいかなかったら「バックアップから復元」で戻せます。

    ステップ 3. 見た目を確認する¶

    字幕のレイアウト（テンプレート）は作り直されているものがあります。 レイアウトを開いて、いつも使っているものを選び直してください。

    • 「テンプレートの再生成」 を 1 回押すと、表示がおかしいときに直ることがあります
    • 縁取りの太さや色が変わって見えるときは、レイアウトデザインで調整してください

    ステップ 4. 音が出るか・字幕が出るかを確かめる¶

    配信で使う前に、いつもの流れを一通り試してください。

    • マイクから字幕が出るか（出ないときは音声認識できないとき）
    • 翻訳が出るか
    • 読み上げが鳴るか
    • OBS に字幕が出るか

    自分でやり直す必要があるもの（ここがいちばん大事）¶

    自動では戻らないので、自分で設定し直してください。

    やり直すもの 何が起きるか どうすればいいか
    プラグインの ON / OFF 「v2.3設定を移行」ではプラグインの有効・無効の一覧を取り込みません（v3.0 側で読み込まれているプラグインと食い違うのを防ぐため） 移行のあとプラグインの有効化を開いて、使っていたものが入っているか確認してください
    支援キー（FANBOX） 支援者認証の状態も「v2.3設定を移行」では取り込みません 支援機能が外れていたら支援機能の有効化で入れ直してください
    翻訳エンジンの選択 提供が終わったエンジン（Google 無料翻訳 / IBM Watson）を選んでいた枠は「翻訳しない」になります 標準設定項目で選び直してください
    自分で作った・もらったプラグイン 公式配布以外のプラグインは読み込めません。土台が .NET 10 に変わったためです 配布元に v3.0（.NET 10）対応版を出してもらってください
    追加の字幕テンプレート（ext-pack） ListAddTime / SmartScroll / Smart_Vue の 3 つは無くなりました。残り 40 本も作り直されています レイアウトから選び直してください
    VRChat OSC のシナリオ原稿 TEXT 行と、何も書いていない行の送り先が入れ替わりました 移行のときに「書き直しますか？」と聞かれるので はい を選んでください
    Alibaba 翻訳のキー v2.3 では中身が動いていなかったため、キーを入れていない人がほとんどです。v3.0 で実際に呼ぶようになりました 使う場合は SecretId / SecretKey を入れてください

    お知らせに出るもの¶

    「v2.3設定を移行」のあと、以下のようなお知らせが出ることがあります。 これは「あなたの環境で実際に起きた変更」なので、目を通してください。

    • 翻訳API 1〜4：古い保存形式（一覧の並び順）を、エンジンの番号に直しました
    • 翻訳エンジンが「翻訳しない」になった：Google 無料翻訳 / IBM Watson は提供が終わっています
    • Claude / OpenRouter のキー欄：v2.3 初期の不具合で API キー欄にモデル名が入っていたものを、モデル欄へ戻しました
    • Gemini Flash Lite：選択肢は同じですが、実際に呼ぶモデルが 2.5 Flash Lite → 3.5 Flash Lite に変わっています
    • 縁取りの言語別調整：v2.3.128 以前はこの項目が保存されない不具合がありました。太さが残っていれば自動でオンに戻します

    v3.0 で画面が変わったところ¶

    「前はここにあったのに無い」となりやすいところです。

    探しているもの v2.3 での場所 v3.0 での場所
    母国語と言語の表示 左メニュー「母国語と言語の表示」 「レイアウトデザインの選択」→ 見た目を調整する → 表示内容
    フォント設定と配置 左メニュー「フォント設定と配置」 「レイアウトデザインの選択」→ 見た目を調整する → 文字 / 配置
    色（表示色や背景色） 左メニュー「色（表示色や背景色）」 「レイアウトデザインの選択」→ 見た目を調整する → 色
    字幕のタイミング 左メニュー「字幕のタイミング」 左メニューにそのまま残っています（「見た目を調整する」→ タイミング からも開けます）
    OBS に貼るアドレス レイアウトデザインの中 左メニューに 「OBSからの参照設定」 として独立しました
    初心者モード あり なくなりました（隠していた項目が整理されたため）
    設定項目が見つからない — 左メニューの 「設定をさがす」 に項目名を入れて Enter を押すと、その設定まで飛びます
    配信中によく使うもの — 左メニューの先頭に コックピット が増えました

    2. くわしく知りたい方へ¶

    ここから先は、内部で何が変わったのかを知りたい方・AI に読ませて調べたい方向けの内容です。 操作だけしたい方はここまでで大丈夫です。

    2-1. 土台が .NET Framework 4.8 → .NET 10 になりました¶

    配布の形が変わった¶

    v2.3 は Windows に標準で入っている .NET Framework 4.8 の上で動いていました。 .NET 10 は標準では入っていないため、ランタイムを同梱した「自己完結型」で配布しています。

    v2.3 v3.0
    実行基盤 .NET Framework 4.8（Windows 同梱） .NET 10（アプリに同梱）
    ランタイムの導入 不要 不要（同梱しているため）
    配布物のサイズ — 展開後でおよそ 1GB（内蔵ブラウザの Chromium 同梱が無くなったぶん、v2.3 より小さい）
    起動する実体 YNC_Neo.exe（ネイティブ EXE） YNC_Neo.exe（.NET 10 ホスト＋YNC_Neo.dll）

    設定の保存先が変わった理由¶

    ユーザー設定は %LOCALAPPDATA%\YNC_Neo\<アプリ識別フォルダ>\<バージョン>\user.config に入ります。 この「アプリ識別フォルダ」の名前は実行アセンブリ名から計算されるため、 YNC_Neo.exe → YNC_Neo.dll に変わったことで別のフォルダ名になります。

    v2.3 のフォルダ名は YNC_Neo.exe_Url_<ハッシュ> でしたが、v3.0 では .exe が付かない別名になります。 Settings.Default.Upgrade() は同じフォルダの中の古いバージョンしか探さないため、 この乗り換えは標準の仕組みでは救えません。

    そこで v3.0 は初回起動時に、会社フォルダ（%LOCALAPPDATA%\YNC_Neo）の兄弟フォルダから いちばん新しい user.config を探して自分の保存先へコピーします。 この自動コピーは値をそのまま持ってくるだけなので、 意味が変わった項目の変換は「v2.3設定を移行」ボタンが担当します。

    安全側の作りになっており、以下が保証されています。

    • 自分の user.config が既にあるときは上書きしない
    • 1 度取り込んだら会社フォルダに印（.net10-settings-imported）を残し、二度と走らない
    • 取り込む前後に XML として読めるかを検証する
    • 見つけたのに取り込めなかったときは、黙って既定値に戻さずダイアログで知らせる

    「v2.3設定を移行」があえて取り込まないもの¶

    手動の移行は「利用者が選んだ値」だけを運びます。以下は意図的に対象外です。

    取り込まないもの 理由
    プラグインの有効／導入一覧（PluginEnableList / PluginInstalledList） 読み込み済みのプラグインと食い違うと、保存のたびに今動いているものの状態で上書きされるため
    支援者認証の状態（FanBoxData*） プロファイルの適用と同じく、環境に紐づく情報のため
    翻訳の利用回数（TransCount*） v2.3 の集計を足すと、今月の上限判定が狂うため
    前回起動した版の控え（VersionDataItem） v2.3 の版を持ち込むと、次回起動で毎回「版が変わった」と判断され、テンプレートの再コピーが走るため
    初回案内・移行の印（HasCompletedFirstRun ほか） v3.0 側の一度きりの処理が走らなくなるため

    また、以下は移行のときではなく v3.0 が読み込み時に自分で直すので、二重には変換しません。

    • API キーの暗号化方式（XOR → DPAPI）
    • Gemini の廃止モデル名の読み替え
    • PluginEnableList から PluginInstalledList への分離

    自作プラグインを持っている方へ¶

    ホストは Assembly.LoadFrom でプラグイン DLL を読みますが、 .NET Framework 4.8 向けにビルドされた DLL は .NET 10 のホストでは読み込めません。 公式配布の 64 本はすべて net10.0-windows で再ビルド済みです。

    自作・配布を受けたプラグインは、以下の対応が要ります。

    • ターゲットフレームワークを net10.0-windows へ
    • プラグインは動的読み込みなので EnableDynamicLoading が必要
    • YNC_PluginSdk を参照している場合は、v3.0 に同梱の新しいものへ差し替え （v2.3 の配布物には YNC_PluginSdk.dll がそもそも入っていませんでした）
    • .NET 10 で動かない API（Thread.Abort()、ServicePointManager、Uri.EscapeUriString、 app.config の組み込みセクション）が残っていると起動時に落ちます

    なお、音声ソフトを自動操作する部分（PlayEngine.exe）は意図的に .NET Framework 4.8 のままです。 VOICEROID / CeVIO / A.I.VOICE の自動操作ライブラリに .NET Core 向けの提供が無いためで、 別プロセスとして動くので本体が .NET 10 でも問題ありません。

    2-2. 内蔵ブラウザが CefSharp → WebView2 になりました¶

    ブラウザを使う 4 つのプラグインが、Chromium 埋め込み（CefSharp）から Windows 標準の WebView2 へ切り替わりました。

    プラグイン 変わったこと
    内蔵ブラウザ 描画エンジンが Edge（WebView2）に
    コメントスクリーン連携 同上
    ニコニコ生放送連携 CefSharp 経路を廃止、WebView2 に一本化
    clusterウェブトリガ 画面を持たない読み取りも WebView2 に

    必要なもの：WebView2 ランタイム（Evergreen）。

    • Windows 11 は標準で入っています
    • Windows 10 も、Microsoft Edge が入っていれば一緒に入っています
    • 入っていない場合は、その旨を知らせるメッセージが出ます

    利点：配布物が約 1GB 小さくなり、「どのブラウザ部品が読まれるか」が 起動順で変わる不安定さがなくなりました。

    フォントの扱い

    v2.3 では CEF の制約で、Windows にインストール済みのフォントを わざわざ登録し直していました。WebView2 は標準で使えるのでこの処理は無くなっています。 表示されるフォントが変わって見える場合は、レイアウトデザインの「見た目を調整する」→「文字」で指定し直してください。

    2-3. プラグインの設定画面が作り直されました¶

    設定画面を持つほぼすべてのプラグイン（約 60 本）で、設定画面を WinForms から WPF の共通土台へ移しました。

    • 見た目が統一されました（ボタン・入力欄・ページ切り替えが全プラグインで共通）
    • 表示言語で出し分けられるようになりました。v2.3 の「Slack設定 (Setting)」のように 日本語と英語を 1 つの文に詰め込む書き方はやめています
    • 「何を入れる欄なのか」の説明が付きました。Webhook URL をどこで作るのか、 空のままだとどうなるのかは v2.3 の画面には書いてありませんでした
    • 下書き（Draft）方式になりました。触った項目だけを書き、変更したまま閉じるときは 「保存して閉じる／破棄して閉じる／閉じるのをやめる」の 3 択が出ます
    • 規則の表（正規表現・ホットキー・効果音など）が共通部品になりました。 ファイル形式は v2.3 と同じ引用符つき CSV のままなので、v2.3 に戻すこともできます

    うまく開かないときは

    新しい設定画面が開けなかった場合は、従来の WinForms 画面が逃げ道として残してあります。

    2-4. 読み上げプラグインが大きく変わりました¶

    読み上げの設定画面が全面的に作り直されています。

    新しいもの 内容
    ボイスパレット ボイスを検索つきのタイルで選べる画面。エンジンでの絞り込み・お気に入りに対応
    マイボイス 声の調整（速さ・高さなど）に名前を付けて覚えさせ、一覧からひと押しで呼び出せます
    詳細設定 6 ページ ホーム／条件ルールほか。並びが 2 区切りになりました

    • API で名前を指定して喋らせる場合、マイボイス名も音声の名前として使えます
    • 設定プリセットは「マイボイス」という呼び方に変わりました

    2-5. 字幕と読み上げの同期について¶

    v3.0 では、字幕が読み上げの終わりに合わせて消えるようになりました。 これには代償があります。理解したうえで使ってください。

    1. 字幕は読み上げが終わるまで消えません。 読み上げが遅れれば字幕も遅れます。読み上げ終了の通知が来ない事故のときは、最大 30 秒残ります
    2. 1 枠型のレイアウトでは、次の字幕が前の読み上げの終わりまで待ちます。 待ちが 8 件を超えると、間の字幕は表示されずに飛びます。 1 文ずつ確実に出したい方は、積み上げ型のレイアウトにするか、この同期を切ってください（読み上げの詳細設定 →「タイミングと連携」→「字幕の表示時間を、なるべく読み上げの長さに合わせる」）
    3. エンジン側のアプリが音を鳴らす方式では、本来の精度が出ません。 CeVIO / A.I.VOICE / ITVoice / VoiSona は待ち時間の申告が 0 になります。 AssistantSeika とブラウザ読み上げは通知そのものが無いため、プラグイン側で即座に解除します（＝同期しません）

    保持時間の設定が見当たらないとき

    「次の字幕が来ても保持時間まで待つ」のチェックは、 レイアウトデザイン → カスタマイズ → タイミング タブにあります。 保持を必要としないレイアウトでは、その場に「効きません」と表示されます。

    2-6. 字幕テンプレート（ext-pack）の作り直し¶

    OBS 向けの追加テンプレート 43 本のうち、40 本を共通エンジンへ載せ替え、3 本を削除しました。

    削除されたもの

    テンプレート 理由
    ListAddTime 標準テンプレートとフォルダ名まで同じで、起動時の再同期で必ず上書きされていた
    SmartScroll 同上
    Smart_Vue 標準の Smart と内部 ID（STD-SMART）が衝突し、レイアウト名の復元が別のテンプレートへ飛んでいた

    直ったもの

    • 文字サイズ・行間の設定が最初から効かなかった問題（40 本全部にありました）
    • 翻訳行に設定が届かなかった問題（2 言語目以降が未実装でした）
    • 認識・翻訳・読み上げまで一緒に止まる問題
    • オフライン時に真っ白になる問題（外部サイトから部品を読んでいました）
    • OBS で下のゲームが見えない問題（背景を不透明に塗っていました）
    • 常時 CPU を食う問題（終わらないアニメーションが入っていました）

    配色の出どころを theme.css に一本化し、テンプレート想定値の版番号を上げてあります。 一度でも ext-pack を選んだことがある方は、レイアウトを選び直してください。
