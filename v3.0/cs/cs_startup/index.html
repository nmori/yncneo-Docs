    はじめての設定¶

    ゆかコネNEO v3.0 のドキュメントです。v2.3 をお使いの方は v2.3 版のこのページ を、違いを知りたい方は v2.3 から v3.0 への移行 をご覧ください。

    ゆかコネNEO を入れたあと、字幕が出て配信ソフトに載るまでの手順です。

    v3.0 には 3 ステップのセットアップ案内が付いています。まずはそれに沿って進めてください。 案内を閉じてしまった方・手で設定したい方は、後半の「手で設定する」を見てください。

    前半：セットアップ案内に沿って進める¶

    初回の起動で 「はじめてのセットアップご案内」 が自動で開きます。 閉じてしまった場合は、左メニューのいちばん上あたりにある 「はじめてのセットアップご案内」 から、いつでも開き直せます。

    画面の上にステップ番号（1 / 3 など）と進捗バーが出ます。 下には 戻る / つぎへ / はじめる があります。

    ステップ 1／3：あなたのこと・やりたいこと¶

    名前を決める

    字幕に出る名前です。あとからいつでも変えられるので、適当で大丈夫です。

    あなたが話す言葉を選ぶ

    この言葉を基準に翻訳します（日本語が既定）。

    翻訳して出す言葉を選ぶ

    「言葉をもっと足す」で最大 4 つまで増やせます。

    やりたいことを 1 つ選ぶ

    選ぶと、字幕の見た目と翻訳先がまとめて設定されます。

    「やりたいこと」の 4 つの選択肢

    選ぶもの どうなるか
    配信で翻訳字幕を出したい 話した内容を訳して、話した言葉と一緒に並べて出します
    VRChatなどで会話をサポートしたい 飾りを省いて、読みやすさ優先の見た目にします
    会議や動画の記録に使いたい 翻訳せず、話した内容を上に流しながら残します
    まずは試してみたい いちばん無難な設定ではじめます

    自分でレイアウトを選びたい

    「自分でレイアウトを選ぶ」を開くと、テンプレートを直接えらべます。 4 つのカードは「よく使う組み合わせ」を一発で当てるための近道なので、 こだわりがある方はこちらからどうぞ。

    適用する前に復元ポイントが作られます

    おすすめ設定を当てると、字幕の見た目やタイミングが置きかわります。 当てる前に自動で復元ポイントを作るので、気に入らなければ 「設定保存・復元」→「バックアップから復元」で元に戻せます。 （初回のセットアップ中は、確認のダイアログは出ません。まだ守る設定が無いためです）

    ステップ 2／3：声を入れる¶

    音声認識に何を使うかを選びます。

    このステップは、いまパソコンに入っているものを見て候補を出します。 ウィザードを開いたまま別のツールを入れた場合でも、 このステップに戻ってくると候補が組み直されます。

    出てくる候補 説明
    ブラウザの音声認識を使う 追加のインストールは要りません。Chrome か Edge があれば、そのまま使えます
    Parapper を使う（入っている場合のみ） このパソコンの中だけで動きます。ネットにつながっていなくても使えて、動作も軽めです
    UDトーク を使う（入っている場合のみ） 認識の精度が高い音声認識です。使う前に UDトーク側で接続しておく必要があります

    選んだら 「音声認識の画面をひらく」 を押します。

    ブラウザがマイクを聞いてきたら「許可」

    ブラウザがマイクの使用許可を聞いてきます。ここで「許可」を選ばないと認識できません。 あとから聞かれなくなってしまった場合は、音声認識できないときをご覧ください。

    UDトークを選んだとき

    ゆかコネ側からは UDトーク を起動できません。 先に UDトーク側で接続してから、次へ進んでください。 つながると「UDトークにつながりました」と表示されます。

    ステップ 3／3：配信ソフトに出す¶

    配信ソフト（OBS など）のブラウザソースに貼るアドレスが出ます。

    1. 「配信ソフトへテスト字幕を送る」 を押して、配信ソフト側に字幕が出るか確かめます
    2. 出ていれば 「はじめる」 を押して終わりです

    アドレスの渡し方は 2 通り

    • ドラッグ＆ドロップ：「to OBS」の所をマウスでつかんで、配信ソフトの画面に落とすと一発で入ります
    • コピーして貼る：アドレスをダブルクリックするとコピーされます。OBS の「ブラウザ」ソースに貼ってください

    文字がすごく小さく見える場合

    OBS がサイズを自動で決めているためです。 OBS のブラウザソース → プロパティにある幅と高さを小さくしてみてください（たとえば 幅800／高さ300）。

    終わったあとの確認¶

    左メニューのいちばん上の コックピット を開いてください。

    • 字幕が出るか確かめる：いま出ている字幕が表示されます。出ていなければ 表示テスト を押します
    • 配信ソフトに出す：貼るアドレスと、コピーボタンがあります

    案内をもう一度出したいとき

    ウィザードの下にある 「次回から表示しない」 のチェックを外したまま閉じると、 次に立ち上げたときにまた案内が出ます。 最後まで進めた場合は、次回から出なくなります。

    後半：手で設定する¶

    セットアップ案内を使わずに、左メニューから順に設定する場合の手順です。 各項目の詳しい説明は標準設定項目にあります。

    1. あなたの話す言語・名前¶

    左メニュー → 共通設定項目 → あなたの話す言語・名前

    • 名前：字幕や、コラボレーション時に使われます
    • 話す言語：翻訳の基準になります

    2. 音声入力の設定¶

    左メニュー → 共通設定項目 → 音声入力の設定

    初めてなら ブラウザ（Chrome / Google音声認識） が簡単です。 選択肢にはバッジ（簡単／スマホ利用／応用／追加導入／限定機能）が付いているので、 「簡単」のものから試してください。

    3. 翻訳の設定¶

    左メニュー → 共通設定項目 → 翻訳の設定

    • 翻訳先の言語を最大 4 つまで選びます
    • 翻訳エンジンは 「共用翻訳サーバ」 が無料ですぐ使えます

    共用翻訳サーバについて

    多くの方が使うので、時々遅くなることがあります。 自分専用の翻訳を使いたい場合は、あとから オプション設定で API キーを入れられます。 支援いただくと、企業向けの高品質な翻訳エンジンが使えます （支援の概要）。

    4. レイアウトデザインの選択¶

    左メニュー → レイアウトに関する設定 → レイアウトデザインの選択

    • 多言語 が一番見やすくておすすめです
    • 見た目を細かく直したいときは 「見た目を調整する」 を押します
    • 選べるものの一覧はレイアウトにあります

    5. 音声認識をはじめる¶

    画面上部の 音声認識画面 ボタン（マイクのアイコン）を押すと、認識用のブラウザ画面が開きます。 開いたら 「Start」 を押して認識開始です。

    うまく認識しないときは

    • ブラウザのマイク設定を確認してみましょう
    • 少し大きめの声ではっきり話してみてください
    • 周囲の騒音が少ない環境だと認識精度が上がります
    • それでもダメなときは音声認識できないときへ

    使うブラウザを変えたい

    どのブラウザで動かすかは、オプション設定の 「ブラウザのオプション」で変えられます。 Google音声認識を使うなら Chrome、Microsoft音声認識を使うなら Edge を選んでください。

    6. OBSからの参照設定¶

    左メニュー → レイアウトに関する設定 → OBSからの参照設定

    ここに配信ソフトへ貼るアドレスがあります（v3.0 で独立した画面になりました）。 言語ごとに別々のブラウザソースとして取り込みたいときは、 「応用パターン（１言語ごとの取り込み）」 を開いてください。

    うまくいかないとき¶

    症状 見るところ
    字幕が出ない 左メニュー → トラブルシュート → 動作チェック。赤くなっている項目が原因です
    音声認識が動かない 音声認識できないとき
    OBS に出ない 配信ソフトに取り込む
    設定項目が見つからない 左メニューの 「設定をさがす」 に項目名を入れて Enter
    そのほか こんなときは / ヘルプが欲しいとき

    設定はいつ保存される？

    設定は変更したときと、アプリ終了時に保存されます。 次回起動時には同じ設定で始められるので、毎回設定し直す必要はありません。
